Do it in code

The same conversion, running on your machine

If the point is that your data must not go anywhere, then run the conversion yourself. This script reads a file from disk and writes the result to disk. Nothing is sent over the network, because the script never opens a socket.

import csv
import json
import sys

# Read from a file on disk. Nothing leaves this machine.
with open("data.json", encoding="utf-8") as f:
    rows = json.load(f)

if isinstance(rows, dict):
    rows = [rows]

fieldnames = list(dict.fromkeys(k for row in rows for k in row))

with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames, restval="")
    writer.writeheader()
    writer.writerows(rows)

print(f"wrote data.csv ({len(rows)} rows)", file=sys.stderr)

A local script - the file is read and written on the same machine

That is the whole point: a converter that runs on your machine cannot leak your data, because there is no second machine to leak it to. The browser tool above does the same thing - it just removes the step of saving a script and installing Python.

Want proof rather than a promise? Press Verify: nothing uploaded on any HopConvert page. It opens a live request log built from your own browser Performance API and shows every request the page made after your data arrived. If your payload was going anywhere, it would be listed there.

FAQ

Frequently asked questions

Direct answers about where your JSON goes, and what to do if it must not go anywhere.

Is my JSON uploaded to a server?
No. The page reads the file with the FileReader API and parses it with JSON.parse, both of which run locally in the browser tab. The conversion itself never touches the network.
Can I convert sensitive or regulated data?
Yes, and you can verify it rather than take it on trust. Press "Verify: nothing uploaded" to open a live log of every request the page made. Your payload appears nowhere in that list, because no request carried it.
Does it work offline?
Once the page has loaded, yes. The converter is pure client-side JavaScript, so it keeps working with the network disconnected. The only thing you lose offline is the page itself and the ads.
Do I need to install anything?
No. There is no upload, no account and no install. Paste the JSON and download the file. If you would rather script it, the Python snippet above does the same conversion locally.
What about the ads on the page?
The ad network can see that the page was viewed - that is how ad targeting works - but it never sees what you typed, because nothing you type is ever sent. The request log on the page makes that distinction visible: ad requests are listed as part of the page baseline, and any request made after your data arrived is flagged.
