The jq and Python one-liners

Two short versions of the same job. jq is the fastest when it is already on your machine, and Python is the one that always works.

# Every object in the array becomes one CSV row.
jq -r '.[] | [.id, .name, .city] | @csv' users.json > users.csv

jq - pick the fields you want, straight into a CSV file

import csv
import json

with open("users.json", encoding="utf-8") as f:
    items = json.load(f)

# Accept both a bare array and a single object.
rows = items if isinstance(items, list) else [items]

with open("users.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=rows[0].keys())
    writer.writeheader()
    writer.writerows(rows)

Python - the standard library version

The @csv filter in jq is the part people miss: it quotes and escapes each field for you, so a name containing a comma does not split the row in two. In Python, csv.DictWriter does the same job.

Neither snippet cares what the array elements look like as long as they are objects with the same keys. When the keys differ from row to row, the nested objects tool keeps every value instead of dropping the extras.

Worked example

A worked example

A three-element array of objects, and the three-row table it becomes.

orders.json

[
  {"order_id": 1001, "customer": "Ada Lovelace", "total": 42.5},
  {"order_id": 1002, "customer": "Grace Hopper", "total": 17.0},
  {"order_id": 1003, "customer": "Alan Turing", "total": 99.99}
]

orders.csv

order_id,customer,total
1001,Ada Lovelace,42.5
1002,Grace Hopper,17.0
1003,Alan Turing,99.99

Three elements, three rows, and the header taken from the keys. The converter above defaults to a tab delimiter so the file pastes straight into Excel - switch it to comma in the settings to match this example. The array order is preserved, which matters when the array is already sorted the way you want the sheet.

FAQ

Frequently asked questions

The short version of everything people ask about JSON arrays.

What does a JSON array look like?
A JSON array starts and ends with square brackets and holds values separated by commas: [{"id": 1}, {"id": 2}]. An array of objects - a list of records - is the shape almost every REST API returns for a collection.
How do I convert a JSON array of objects to CSV?
Read the array, then write one row per element with the keys of the first object as the header. In jq that is jq -r ".[] | @csv", in Python it is csv.DictWriter, and in the browser it is the converter above.
How many rows will my CSV have?
One row per array element, plus one header row. An array of 1,000 objects gives you 1,000 data rows. The preview under the converter shows the exact count before you download.
What if my JSON is one object, not an array?
It still works. The converter treats a single object as an array of one, and the Python snippet does the same with the isinstance(rows, dict) check. You get a header row and one data row.
What if the objects have different keys?
The header is built from every key that appears anywhere in the array, and rows that are missing a key get an empty cell for it. Nothing is dropped - which is the usual failure mode of a converter that only reads the first object.
